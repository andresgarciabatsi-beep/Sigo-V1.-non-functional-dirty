Descripción

INFO

El módulo GY-91 integra el IMU MPU6500 y el barómetro BMP280, logrando un total de 7 grados de libertad (DoF) y contiene todo lo necesario para realizar rastreo de movimiento espacial de un Drone o UAV. Combina un giroscopio de 3 ejes, un acelerómetro de 3 ejes y un altímetro en un mismo chip.

El IMU MPU6500 integra un DMP (Procesador digital de movimiento) capaz de realizar complejos algoritmos de captura de movimiento de 6 ejes. Para una captura precisa de movimiento rápido y lento, posee un rango de escala programable de 250/500/1000/2000 grados/seg para el giroscopio, 2g/4g/8g/16g para el acelerómetro.

El sensor de presión barométrica BMP280 (evolución del BMP180) posee alta precisión y un bajo consumo de energía. Ofrece un rango de medición de 300 a 1100 hPa (Hecto Pascal). Basado en tecnología BOSCH piezo-resistiva con gran robustez EMC, alta precisión y linealidad, así como con estabilidad a largo plazo. Presenta diversas mejoras respecto al sensor BMP180 como: mejor resolución de presión y temperatura, mejor precisión, mejores filtros digitales y un menor consumo de energía.

Los sensores MPU6500 y BMP280 comparten el mismo bus de comunicación I2C. La integración con Arduino a nivel de software es muy sencilla pues existen librerías listas para ser usadas. A nivel de hardware el modulo incluye un regulador de 3.3V en placa, además de resistencias pull-up en el bus I2C.

El módulo GY-91 posee alta integración y precisión, ideal para ser utilizado en Drones, solo basta añadir un Módulo GPS y podremos construir un sistema de navegación autónoma. 

ESPECIFICACIONES TÉCNICAS

  • Módulo GY-91: MPU6500 + BMP280
  • Voltaje de operación: 3V/3.3V~5V DC
  • Interfaz de comunicación: I2C y SPI
  • Comunicación compatible con 3.3V o 5V
  • Sensor IMU: MPU6500
    • Rango Acelerómetro: ±2g, ±4g, ±8g, ±16g
    • Rango Giroscopio: ±250Grad/Seg, ±500Grad/Seg, ±1000Grad/Seg, ±2000Grad/Seg
    • Conversor AD: 16 Bits (salida digital)
    • Grados de libertad (DoF): 6
    • Dirección I2C: 0x68 (pin ADO a GND) / 0x69 (pin ADO a VCC)
  • Sensor BARÓMETRO: BMP280
    • Rango de Presión: 300 a 1100 hPa
    • Resolución: 0.16 Pa
    • Precisión absoluta: 1 hPa
    • Medición de temperatura incluida
    • Resolución de temperatura: 0.01°C
    • Precisión Temperatura: 1°C
    • Frecuencia de Muestreo: 157 Hz (máx.)
    • Dirección I2C: 0x76
  • Regulador de voltaje integrado en placa
  • Ultra-bajo consumo de energía
  • Completamente calibrado
  • Dimensiones: 20*14*3 mm

CONEXIÓN

  • VIN: Alimentación voltaje 5V
  • 3V3: Salida 3.3V
  • GND: 0V Tierra
  • SCL: I2C Clock / SPI Clock
  • SDA: I2C Data / SPI Data Input
  • SDO/SAO: SPI Data output / I2C Slave Address configuration pin
  • NCS: Chip Select for SPI mode only for MPU6500
  • CSB: Chip Select for BMP280
