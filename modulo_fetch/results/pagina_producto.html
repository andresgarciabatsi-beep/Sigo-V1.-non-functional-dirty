La Raspberry Pi 5 de 8GB está diseñada para proyectos avanzados y tareas exigentes, como servidores domésticos, estaciones de trabajo ligeras y proyectos de inteligencia artificial. Con un procesador Arm Cortex-A76 de cuatro núcleos a 2.4 GHz y 8GB de RAM LPDDR4X-4267, esta versión es ideal para aplicaciones que requieren alto rendimiento y capacidad multitarea.

Una de las mayores innovaciones de la Raspberry Pi 5 es su puerto PCIe 2.0 x1, que abre un mundo de posibilidades para proyectos avanzados. Este puerto permite aprovechar la velocidad del bus PCIe para conectar dispositivos de alto rendimiento como unidades SSD NVMe, mejorando significativamente las capacidades de almacenamiento y velocidad en proyectos intensivos. Además, el PCIe es ideal para tareas de inteligencia artificial, ya que admite aceleradores de IA como el HAILO-8 IA o los nuevos módulos de cámaras con IA, brindando un rendimiento excepcional en aplicaciones de visión artificial y aprendizaje automático.

La fuente de alimentación recomendada es una Power Delivery (PD) de 27W, necesaria para alimentar la placa y habilitar las salidas USB a plena potencia. También es compatible con una fuente de alimentación de 15W, pero esto limitará las salidas USB a un máximo de 0.6A por puerto. Además, el RTC integrado requiere una batería CR2032 para su funcionamiento.

Se recomienda una refrigeración activa o un sistema de disipación pasiva grande para mantener un rendimiento óptimo. En sistemas activos, recomendamos el ventilador activo oficial o la caja con ventilador dual. Si prefieres un sistema pasivo, la caja Zero Noise es una excelente opción.

Características

  • Procesador: Broadcom BCM2712 2.4GHz quad-core 64-bit ARM Cortex-A76.
  • Memoria RAM: 8GB LPDDR4X-4267 SDRAM.
  • GPU: VideoCore VII con soporte para OpenGL ES 3.1 y Vulkan 1.2.
  • Conectividad: Wi-Fi 802.11ac, Bluetooth 5.0 y BLE, Gigabit Ethernet con soporte PoE+.
  • Puertos: 2 USB 3.0, 2 USB 2.0, 2 salidas HDMI 4Kp60.
  • Almacenamiento y Expansión:
    • Ranura microSD con soporte para SDR104.
    • Puerto PCIe 2.0 x1 para unidades SSD NVMe y aceleradores de IA.
  • Fuente de Alimentación: USB-C 5V/5A con soporte Power Delivery.
  • Dimensiones: 85mm x 58mm.

Aplicaciones Recomendadas

  • Estaciones de trabajo ligeras.
  • Proyectos avanzados de inteligencia artificial.
  • Servidor doméstico y desarrollo de software avanzado.
  • Proyectos intensivos en almacenamiento gracias al puerto PCIe.

Preguntas Frecuentes

¿Qué ventajas ofrece el puerto PCIe?
El puerto PCIe 2.0 x1 proporciona una alta velocidad para conectividad de dispositivos como unidades SSD NVMe, aceleradores de IA como el HAILO-8 IA, y para uso avanzado de los nuevos módulos de cámaras con inteligencia artificial.

¿Qué fuente de alimentación se recomienda?
Se recomienda una fuente de alimentación Power Delivery (PD) de 27W para habilitar la salida completa en los puertos USB. También es compatible con una fuente de alimentación de 15W, pero en este caso las salidas USB estarán limitadas a 0.6A por puerto.

¿Qué opciones de refrigeración son ideales?
Para refrigeración activa, recomendamos el ventilador activo oficial o la caja con ventilador dual. Para sistemas pasivos, la caja Zero Noise es la mejor opción.
